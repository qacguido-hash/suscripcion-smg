# S&G Expendedoras — app de gestión

Publicada como página privada en claude.ai: https://claude.ai/artifact/LECc5G6xbvVBwaq7J8PNcR

- `sg-expendedoras.html`: el código de la app (una sola página, sin dependencias).
- Datos en la base del artifact (colecciones `productos`, `stock`, `relev`, `competidores`,
  `proveedores`, `maquinas`, `config`). Fotos de productos guardadas como assets del artifact.
- Etapa 1: productos, costos, competencia con promos, comparación de precios, stock con
  vencimientos, lista de compras, máquinas con slots 1–60 y reposición, gastos por máquina.
- Etapa 2 (pendiente): importar ventas del panel de la máquina, rentabilidad y ventas por horario.
