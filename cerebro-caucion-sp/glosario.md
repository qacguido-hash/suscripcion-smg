# Glosario

| Término | Significado |
|---|---|
| Tomador | Quien contrata la póliza y debe cumplir la obligación garantizada. |
| Asegurado | Beneficiario de la garantía (quien cobra si el tomador incumple). |
| Cúmulo | Suma total de pólizas vigentes de un tomador o grupo económico. |
| Contragarantía | Garantía que da el tomador a la aseguradora para recuperar lo que esta pague. |
| Recupero | Lo que la aseguradora le cobra al tomador después de pagar un siniestro. |
| Facultades | Montos hasta los cuales cada persona puede aprobar un negocio. |
